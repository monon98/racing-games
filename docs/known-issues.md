# 已知问题

> 记录尚未解决、计划后续处理的问题。解决后在对应条目标注处理方式并移入 `docs/discussion-log.md`。

## 1. 高速时车与赛道碰撞判断存在问题（待处理）
- 现象：速度较高时（尤其是顶着护栏、急弯内高速贴墙），车与赛道/护栏的碰撞判断可能失效：出现穿墙、异常弹跳或碰撞反馈不及时。
- 推测原因：cannon-es 无 CCD（连续碰撞检测），高速下薄护栏/路面 Trimesh 的接触采样不足；物理子步固定在 1/60（120Hz 会导致悬架失稳，不能直接加密）。
- 临时缓解：转向限速 50km/h 已在机制上降低弯中速度；尽量避免满油门直撞护栏。
- 计划：后续评估“速度相关子步加密 + 护栏加厚/合并碰撞体”或替换更稳的碰撞方案。

## 2. 环境装饰无碰撞（低优先级）
- 树、石头等环境物体为纯视觉（`src/track/environment.ts`），车可穿过。放置时已避开路面，正常行驶不会碰到；后续可给树干/巨石加静态碰撞体。

## 3. 复杂赛道野地高速行驶仍会短暂离地
- 无护栏直行高速碾野地时，车身离地最高约 3~4m 后会受重力落回（纯物理行为）；赛道内坡度 ≤12% 且四轮全离地时上升速度钳制在 2m/s，幅度较小。
- 缓解：脱轨判定（半宽 + 0.5m / 0.4s）会尽快重生回赛道；若后续觉得幅度大可做“地形贴合/更强悬挂”。

## 4. 护栏碰撞为刚体近似
- 轮位碰撞盒是静态 Box（0.44 × 0.84 × 0.44），与真实车轮圆柱/悬架姿态有差异；极端擦角下可能出现视觉穿模或碰撞反馈延迟。
