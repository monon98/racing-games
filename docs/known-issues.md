# 已知问题

> 记录尚未解决、计划后续处理的问题。解决后在对应条目标注处理方式并移入 `docs/discussion-log.md`。

## 1. 高速时车与赛道碰撞判断存在问题（2026-10-25 大幅缓解）
- 现象（历史记录）：速度较高时（尤其是顶着护栏、急弯内高速贴墙），车与赛道/护栏的碰撞判断可能失效：出现穿墙、异常弹跳或碰撞反馈不及时。
- **2026-10-25 复现实验结论**：在最小独立场景（水平地面 + 直墙）下用当前引擎实测，55 m/s（≈200km/h 极速）正撞全油门、15° 浅角 45 m/s 贴墙蹭行、双段护栏 0.01m 接缝穿越、45° 边缘角擦，**全部被接住（穿透 0、垂直弹跳 ≤2.6m/s、无翻车）**——历史问题大概率来自旧引擎状态，2026-10-20 的"立即回弹+减速"与后续稳定器已覆盖主要工况。四个场景固化为 `tests/barrier-collision.spec.ts` 回归。
- 已实施加固：护栏碰撞盒向路外方向加厚 0.8m（`BARRIER_COLLIDER_DEPTH_EXTRA`），前内侧面/可见面不变——高速下未接住的接触体下一步仍与护栏重叠，求解器持续修正。
- 物理子步保持 1/60 不变（120Hz 会松油俯仰失稳，勿全局加密；若真实轨道仍偶然穿墙，再评估"速度相关子步加密"，需把闭环控制改到子步内施加）。
- 遗留不确定性：复杂地形上贴坡护栏的极端组合未逐一复现，由回归测试 + `pnpm dev` 人工试驾继续盯。

## 2. 环境装饰无碰撞（低优先级）
- 树、石头等环境物体为纯视觉（`src/track/environment.ts`），车可穿过。放置时已避开路面，正常行驶不会碰到；后续可给树干/巨石加静态碰撞体。

## 3. 复杂赛道野地高速行驶仍会短暂离地
- 无护栏直行高速碾野地时，车身离地最高约 3~4m 后会受重力落回（纯物理行为）；赛道内坡度 ≤12% 且四轮全离地时上升速度钳制在 2m/s，幅度较小。
- 缓解：脱轨判定（半宽 + 0.5m / 0.4s）会尽快重生回赛道；若后续觉得幅度大可做“地形贴合/更强悬挂”。

## 4. 护栏碰撞为刚体近似（2026-10-20 已改为整车单一碰撞盒后基本缓解）
- 轮位碰撞盒（0.44 × 0.84 × 0.44 × 4）已移除，碰撞判定改为整车单一 Box（与车身同宽）。
- 仍存在的近似：Box 与真实车身曲面（座舱/轮子）有差异；极端擦角下可能出现视觉穿模或碰撞反馈延迟。
