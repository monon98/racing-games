# 已知问题

> 记录尚未解决、计划后续处理的问题。解决后在对应条目标注处理方式并移入 `docs/discussion-log.md`。

## 1. 高速时车与赛道碰撞判断存在问题（2026-10-28 根因修复）
- 现象（历史记录）：速度较高时（尤其是顶着护栏、急弯内高速贴墙），车与赛道/护栏的碰撞判断可能失效：出现穿墙、异常弹跳或碰撞反馈不及时。
- **2026-10-28 根因找到并修复**：静态护栏 Body 构造期 AABB 在原点，之后设置 `position`/`quaternion` 不会自动刷新；`SAPBroadphase` 按错误 `lowerBound` 排序并提前 `break`，护栏 pair 根本不进入 narrowphase。表现为第一次脱轨重生后直接穿墙、反复脱轨（发卡弯 12 秒 6 次、碰撞回调 0 次）。修复：护栏创建后与 `CarPhysics.addGround()` 均显式 `updateAABB()`；`tests/track.spec.ts` 固化三预设护栏 AABB 角点校验，`tests/barrier-respawn.spec.ts` 固化“出轨→重生→满舵”不重复脱轨。
- **2026-10-25 复现实验结论**：在最小独立场景（水平地面 + 直墙）下用当前引擎实测，55 m/s（≈200km/h 极速）正撞全油门、15° 浅角 45 m/s 贴墙蹭行、双段护栏 0.01m 接缝穿越、45° 边缘角擦，**全部被接住（穿透 0、垂直弹跳 ≤2.6m/s、无翻车）**。四个场景固化为 `tests/barrier-collision.spec.ts` 回归。
- 已实施加固：护栏碰撞盒纯向外加厚 1.2m（`BARRIER_COLLIDER_DEPTH_EXTRA`，内侧面与可见内侧面重合；2026-10-28 修正旧公式向内侵入 0.35m 的问题并调高护栏到 1.8m）——高速下未接住的接触体下一步仍与护栏重叠，求解器持续修正。
- 物理子步保持 1/60 不变（120Hz 会松油俯仰失稳，勿全局加密；若真实轨道仍偶然穿墙，再评估"速度相关子步加密"，需把闭环控制改到子步内施加）。
- 遗留不确定性：复杂地形上贴坡护栏的极端组合未逐一复现，由回归测试 + `pnpm dev` 人工试驾继续盯。

## 2. 环境装饰无碰撞（低优先级）
- 树、石头等环境物体为纯视觉（`src/track/environment.ts`），车可穿过。放置时已避开路面，正常行驶不会碰到；后续可给树干/巨石加静态碰撞体。

## 3. 复杂赛道野地高速行驶仍会短暂离地
- 无护栏直行高速碾野地时，车身离地最高约 3~4m 后会受重力落回（纯物理行为）；赛道内坡度 ≤12% 且四轮全离地时上升速度钳制在 2m/s，幅度较小。
- 缓解：脱轨判定（半宽 + 1.2m / 0.4s）会尽快重生回赛道；若后续觉得幅度大可做“地形贴合/更强悬挂”。

## 4. 护栏碰撞为刚体近似（2026-10-20 已改为整车单一碰撞盒后基本缓解）
- 轮位碰撞盒（0.44 × 0.84 × 0.44 × 4）已移除，碰撞判定改为整车单一 Box（与车身同宽）。
- 仍存在的近似：Box 与真实车身曲面（座舱/轮子）有差异；极端擦角下可能出现视觉穿模或碰撞反馈延迟。

## 5. 工程与体验层面的不足（2026-10-27 盘点）
- **浏览器人工验收未闭环**：开发机无可用浏览器，只能由用户本机 `pnpm dev` 试驾；`docs/progress.md` 的人工验收清单（启动页控件、完整冲线、持久化、导出/导入、惩罚显示、暂停、小地图、预设选择、音效、光影）仍未逐项勾选。
- **无移动端/触屏支持**：键鼠输入模型与桌面布局假设，手机/平板无法游玩。
- **CI 未跑测试**：GitHub Actions 只执行 `pnpm typecheck` + `pnpm build`；58 用例依赖本地门禁，回归防护不在流水线上（建议给 workflow 增加 `pnpm test`）。
- **玩法/内容待补**：无录像回放、无多文件 `.gltf + .bin` 导入、无赛道编辑器（自定义只能随机生成）。
- **音画为简化实现**：音效为单声道纯合成（无混音总线/多普勒/环境音）；光影为单太阳 + 2048 阴影图（无级联阴影/夜间/天气）。
- **物理近似**：固定 1/60 子步（120Hz 全局加密会松油俯仰失稳）+ 整车单一碰撞盒；贴坡护栏、极端擦角等组合仍可能视觉穿模（#1/#4）；环境装饰无碰撞（#2）。
- **性能与架构**：单线程 WebGL、赛道几何一次性全量生成（复杂模式 Trimesh 体量较大），无 LOD/实例化；`src/physics/vehicle.ts` 集中大量调参常量（可再拆独立配置模块）；UI 无 i18n。
