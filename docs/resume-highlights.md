# 简历要点与技术复盘

> 本文件面向简历/面试：浓缩项目价值、可量化成果与不足记录。数据截至 2026-10-28，详细过程见 `discussion-log.md`，问题清单见 `known-issues.md`。

## 一句话定位

单人从零实现的**代码生成 3D 赛车游戏**：three.js + 原生 TypeScript + cannon-es；赛道与汽车零外部美术资源、全部程序化生成，含物理手感调优、9 个 spec 的自动化测试与完整文档/协作体系，已具备 GitHub Pages 部署能力。

## 技术栈

TypeScript 7（strict）· Vite 8（rolldown）· three.js 0.185 · cannon-es 0.20 · WebAudio · IndexedDB · localStorage · Vitest · pnpm · GitHub Actions / Pages

## 简历要点（可直接改写进项目经历）

1. **代码生成 3D 赛车游戏（单人全链路）**：three.js 渲染 + cannon-es 四轮悬架物理 + 原生 TS 三页面 SPA（启动/游戏/预览，hash 路由），约 **4,500 行源码 + 1,470 行测试**；车辆模型同一函数仅按颜色区分，赛道几何（路面/护栏/地形/装饰）全部程序化生成，零外部美术素材。
2. **确定性赛道生成与数据交换**：Catmull-Rom 闭环中心线（三条固定预设 + 随机自定义；长度 1.4~2.6km、坡度 ≤12%、弯道加宽 ≤40%、自交检测换种子重试）；赛道元数据随 GLB `userData/extras` 单文件往返，支持 `.glb` 导出与 `.glb/.gltf` 导入，排行榜按 `presetId` 隔离；构建确定性由"两次逐位一致"回归测试保证。
3. **车辆物理与手感调优（数据驱动，非拍脑袋）**：四驱（前轴 0.5 驱动力叠加）、油门缓入、刹车偏置、抗 squat 前馈反扭矩、空中角阻尼；转向为速度敏感曲线 + **梯形速度曲线跟踪器**（角加速度受限软启动、换向恒速过零、√(2a·d) 二次制动零过冲）。满舵稳态半径实测建档（11.1m/s→6.5m、14.6→7.5m、16.6→8.2m），**干净满舵上限 50→60km/h**，直角弯（十字路口）可达性固化为测试。
4. **高速碰撞可靠性工程**：定位“静态体 AABB 不刷新 → SAPBroadphase 排序错位 → 碰撞对丢失”的穿墙根因，护栏创建后与物理注册时强制 `updateAABB()`；护栏加高至 1.8m、碰撞盒纯向外加厚 1.2m + 立即回弹并保留 80% 速度；用最小独立场景实测 55m/s（≈200km/h）正撞、15° 浅角蹭墙、0.01m 接缝、45° 边缘四工况——穿透 0、垂直弹跳 ≤2.6m/s、无翻车，并新增“出轨重生后仍能撞上护栏”永久回归。
5. **自动化测试体系**：**9 个 Vitest spec、58 个用例、约 1,470 行测试**——赛道确定性与平滑/间距、物理手感与翻车回归、GLB 往返、比赛规则纯函数、高速碰撞与重生后碰撞、光影纹素对齐、转向曲线、十字路口可达性；每次交付强制 `typecheck + test + build` 三道门禁，55 次提交按主题单批推进。
6. **渲染管线（Game 与预览页共享）**：ACES 色调映射 + 天空渐变穹顶（雾色=地平线色）+ PMREM 环境反射（车漆金属有真实天光）+ **阴影纹素对齐**（太阳焦点吸附 0.088m 纹素网格，根治移车阴影亚像素抖动）；自定义 ShaderMaterial 会绕过 three 的色调映射链路，改用顶点色 MeshBasicMaterial 规避（踩坑记录入文档）。
7. **包体与性能优化**：rolldown `advancedChunks` 将 three/cannon 拆为独立 vendor 包，主入口从 >500KB 降至 **55KB（gzip 19KB）**；单方向光 + 2048 阴影图 + 像素比上限 2 平衡画质与性能。
8. **音效系统（零素材）**：WebAudio 纯合成——引擎声双锯齿失谐随速度/负载变调、碰撞带通噪声爆点、漂移啸叫；AudioContext 在用户手势内初始化，暂停/结算自动静音，偏好存 localStorage。
9. **持久化与工程化**：原生 IndexedDB（赛道包含 GLB Blob + 排行榜，单活动赛道）+ localStorage；GitHub Pages 自动部署（typecheck+build）；维护需求/进度/决策/已知问题四类文档 + `AGENTS.md` 项目规则 + 本地技能包（`racing-game-dev` skill + 3 份 references），确保 AI 协作与后续迭代可复现。

## 不足与改进方向（如实记录）

> 与 `known-issues.md` #5 一致；面试被问"项目有什么不足"时可照此展开。

- **验证闭环**：浏览器人工验收仍依赖用户本机试驾（开发机无浏览器），自动化无法覆盖真实手感/观感；上线前应补一轮完整人工验收清单。
- **平台覆盖**：仅桌面键鼠，无移动端/触屏；无手柄支持。
- **CI 防护**：GitHub Actions 目前只跑 typecheck + build，**测试未进流水线**（本地 58 用例全绿），补一行 `pnpm test` 即可闭环。
- **玩法广度**：无录像回放、无多文件 `.gltf + .bin` 导入、无赛道编辑器（自定义仅随机）。
- **音画深度**：音效为简化合成（无混音总线/多普勒/环境音）；光影为单太阳 + 2048 阴影图（无级联阴影/夜间/天气）。
- **物理近似**：固定 1/60 子步（120Hz 全局加密会松油俯仰失稳）+ 整车单一碰撞盒；贴坡护栏/极端擦角仍可能视觉穿模；环境装饰无碰撞。
- **性能与架构**：单线程 WebGL、几何一次性全量生成（复杂 Trimesh 较大），无 LOD/实例化；`src/physics/vehicle.ts` 常量集中（可拆独立配置）；UI 无 i18n。

## 面试讲述建议（三个最有料的故事）

1. **阴影抖动 → 纹素对齐**：从"阴影相机跟车"到"焦点吸附光空间纹素网格"，用纯数学单元测试验证整纹素步进/幂等/视锥切换；顺带记录"自定义 ShaderMaterial 绕过色彩管线"的坑。
2. **转向"猛且黏" → 梯形速度曲线**：指数平滑起步一帧吃 11.7% 满锁、过零最慢；改为加速度受限 + vmax + 二次制动，零过冲。测试首轮"单调性"误报，用纯算法离线复现定位到目标点 ±1e-6 抖动（`maxSteerAt` 随残速微移），最终把容差定在能区分真卡顿的 1e-4——体现定位方法与数值敏感性。
3. **满舵过不了十字路口 → 先测后调**：用最小独立场景 + 速度保持器建立"半径-速度"基线，发现加大转角无效（横向力 v²/R 超轮胎极限），改用"保留低中速角度 + 前轴深滑咬合 + 后轴抗自旋"三杠杆，干净满舵上限 50→60km/h，并固化为 40/60km/h 两级回归。
