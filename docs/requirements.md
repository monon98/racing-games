# 需求梳理

> 来源：用户原始需求 10 条（2026-08-11），标注 MVP（最小可玩版）内 / 后续。

| # | 原始需求 | 实现方式 | 阶段 |
| --- | --- | --- | --- |
| 1 | 两个页面：启动页 + 游戏页 | hash 路由 `#/start` / `#/game`，`src/pages/` | MVP |
| 2 | 至少两种模型：赛道、汽车，代码生成；树/石头等非必须 | `src/track/generator.ts`、`src/car/createCar.ts`；环境装饰列入 M3 | MVP（赛道/汽车）/ 后续（环境） |
| 3 | 汽车支持颜色设置，模型函数同一 | 颜色参数传入 `buildCar(color)` | MVP |
| 4 | 赛道初始化自动生成，IndexedDB 存储，GLTF/GLB 导入导出 | `src/track/gltf.ts` + `src/storage/db.ts`；导出 .glb，导入 .glb/内嵌 .gltf | MVP |
| 5 | 赛道简单/复杂两种模式，默认简单 | 简单=随机点 Catmull-Rom 光滑闭环（不要求直线）；复杂=随机 M×N 高度矩阵网格车道 + 可行驶斜坡（发卡弯闭环、交叉净空） | MVP / M2 |
| 6 | 启动页：排行榜（跟随赛道）、开始、颜色、重新生成（选项+清榜提示）、导入/导出、玩家名称 | `StartPage` 全部实现 | MVP |

| 8 | 轮子转动、较真实碰撞、翻车/脱轨、无法正常行驶时重生并给距离+时间惩罚 | cannon-es RaycastVehicle + 翻车/脱轨检测 + 重生惩罚 | MVP |
| 9 | 车与赛道按比例；赛道两边护栏=车高一半 | 常量 `ROAD_WIDTH_MULTIPLIER=6.0`（6 倍车宽，用户要求加宽）+ 弯道按曲率加宽、`BARRIER_HEIGHT_FACTOR=0.5` | MVP |
| 10 | WASD/方向键、空格暂停、返回首页按钮 | `Game.ts` 键盘控制 + HUD 按钮 | MVP |

## 补充规则（已确认）
- 排行榜口径：一局单圈，按用时升序取前 10；同时记录翻车次数等数据但不展示。
- 单活动赛道：数据库只保留一条；重新生成 = 新种子 + 新 id + 清除旧排行榜（有确认弹窗）。
- 重生惩罚：固定时间 +3s；距离惩罚 = 进度回退距离，按 0.1s/m 折算，两者均计入单圈用时。
- 翻车判定：车身上向量与竖直夹角 >70° 持续 1s；脱轨判定：水平偏离中心线 > 半宽 + 0.5m 持续 0.4s。
