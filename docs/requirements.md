## 补充规则（已确认）
- 排行榜口径：一局单圈，按用时升序取前 10；同时记录翻车次数等数据但不展示。
- 单活动赛道：数据库只保留一条；重新生成 = 新种子 + 新 id + 清除旧排行榜（有确认弹窗）。
- 重生惩罚：固定时间 +3s；距离惩罚 = 进度回退距离，按 0.1s/m 折算，两者均计入单圈用时。
- 翻车判定：车身上向量与竖直夹角 >70° 持续 1s；脱轨判定：水平偏离中心线 > 半宽 + 0.5m 持续 0.4s。
- 逆行判定：仅当“车头朝后（与切线反向）且沿车头方向前进 > 2 m/s”持续 3s 触发；倒车不误判。
- 滑行/倒车：松油门缓慢滑行；带转向或正在倒车时松油门快速降速；倒车+转向最高速度 10 m/s（HUD），直线倒车 8 m/s。
- 四轮驱动（2026-10-23，用户要求）：动力改为四驱——前轴每轮在原后驱力基础上**叠加** `force × FRONT_DRIVE_RATIO`（0.5，前轴总驱动力 ≈ 后轴一半），前轮接地时生效、悬空时自然回退为纯后驱（直线 0-100 与极速不变，起步/出弯/爬坡更有力）；倒车+转向保持四轮满力（10 m/s 上限行为不变）。所有四轮每帧都设置发动机力（cannon `wheel.engineForce` 跨帧残留，顺带修掉漏设残留 bug）。
- 驾驶手感包（2026-10-25，用户选定实施）：①油门缓入——踏板指令指数平滑（THROTTLE_RAMP_RATE=14/s，约 0.15-0.2s 到满），起步不窜、四驱咬合更稳；②刹车偏置——前 0.6 / 后 1.4（总容量守恒），压制急刹点头；③前轮贴地——抗 squat 前馈反扭矩（ATI_SQUAT_FACTOR=0.45 × 总驱动力，仅接地+前进+<30m/s 时介入，上限 12000）抵消"推进力作用于重心下方"掀头的静态平衡，让四驱前轴在直线加速也生效；实测量级见 discussion-log；④空中角速度阻尼——完全离地时温和衰减角速度（1.2/s），防抬头 PD 空中不 bang-bang 振荡。
- 高速碰撞加固（2026-10-25，known-issues #1 落地第一批）：护栏碰撞盒向路外方向加厚 `BARRIER_COLLIDER_DEPTH_EXTRA=0.8`（前内侧面位置与可见面不变，纯隐形体积）；新增 `tests/barrier-collision.spec.ts` 四场景验收：极速 55m/s 全油门正撞、15° 浅角 45m/s 贴墙蹭行、接缝穿越、45° 边缘角擦——均要求"穿透 <1m、垂直弹跳有界、无翻车"。物理子步保持 1/60 不变（120Hz 教训；独立场景实测基线穿透为 0，无需子步加密）。
- 音效（2026-10-25，用户选定六项中的批 3）：WebAudio 纯合成（零新依赖，`src/audio/engine.ts`）——引擎声（双锯齿失谐+三角次低音，音高随速度 60→225Hz，低通随负载开合）、碰撞闷响（带通噪声爆点，音量随冲击速度）、漂移啸叫；HUD 右上角 🔊/🔇 静音按钮（状态存 localStorage `racing-audio-muted`）；`AudioContext` 必须在用户手势内 init（开始游戏点击链路），暂停/结算自动静音；node/无 AudioContext 环境安全 no-op。
- 代码分割（2026-10-25，用户选定六项中的批 4）：rolldown `advancedChunks` 把 three / cannon-es 拆为独立 vendor 包——主入口从 >500kB 降到 **55KB**（gzip 19KB）、cannon 99KB、three 666KB（库本体，gzip 169KB）；`chunkSizeWarningLimit` 调至 750（vendor-three 告警无 actionable 意义）。
- 更多预设赛道（2026-10-25，用户选定六项中的批 5）：新增「落日余晖」`sunfall-sweep`（1.8km 大半径高速环道 + 左侧回旋弯）与「回旋花廊」`windmill-corridor`（1.4km 双发卡回旋 + 底部直道），控制点数据固定、id 发布后不可变；逐预设永久回归：构建确定性（两次逐位一致）、长度精确命中（±1m）、逐步航向平滑（<0.25rad）、非邻接最近间距 >25m（实测最窄 32m）、静止 30 帧 ≥3 轮接地可驾驶冒烟。
- 转向顺滑（2026-10-25 用户验收反馈"左右向控制不够顺滑"）：转向从指数平滑改为**梯形速度曲线**（角加速度受限 + vmax + √(2·a·d) 二次制动约束）：起步一帧位移从 ~0.076 rad 降到 ~0.005 rad（软启动）、全锁 0.65rad 约 0.21s 匀速到位无长尾、换向过零段恒速不再发黏、高速 vmax 加成使 S 换向更快；零过冲，贴齐后清残留速度（reset 同步清零）。
- 光影细化（2026-10-25，用户追加选定）：①色彩管线——`ACESFilmicToneMapping` + 曝光（初值 1.05，**用户验收反馈偏亮 → 0.85**，全局明暗优先调曝光这一个旋钮），太阳/半球光强按管线重配；②天空渐变穹顶（顶部深蓝→地平线亮白蓝）替代纯色背景，雾色=地平线色无缝衔接；③PMREM 环境贴图（从天空穹顶烘焙进 `scene.environment`，`environmentIntensity≈0.5`）——车身金属材质（metalness 0.55）不再是死黑反射；④阴影纹素对齐——太阳焦点按"视锥 180m / 2048 贴图 ≈0.088m 纹素"在光空间正交基上吸附网格，**根治移车时的阴影边缘亚像素抖动**（此前只做到跟随，未做到对齐），并配 `shadow.bias/normalBias` 防 acne/光漏；⑤Game 与 TrackPreview 共用 `src/render/lighting.ts` 管线（预览页观感一致）。
- 默认玩家名：“玩家 + 5 位随机字母数字”（空名或本地无存档时自动生成）。
- 重新生成赛道的确认使用自定义对话框（非原生 confirm）。
- 碰撞手感（2026-10-20）：撞护栏后立即沿接触法线回弹（带反弹），并整体适当减速（保留约 80% 速度），避免贴墙蹭行。
- 整车模型（2026-10-20）：车辆整体缩小约 15%（1.7×1.2×3.6m、轮径 0.4m），碰撞判定用整车单一碰撞盒（不再有轮位附加碰撞盒）；赛道基础宽保持 12m，护栏高改为 1.1 × 车高（1.32m）。
- 轨道预设制（2026-10-22）：赛道来源改为“预设轨道（固定布局）+ 自定义随机生成”两类。默认使用预设轨道（先实现一种官方预设，控制点数据固定、布局永不随版本漂移）；原有随机生成（简单/复杂）归档为“自定义”模式保留。重新生成/切换预设/导入仍清除排行榜；预设赛道走平地（Plane + 护栏）管线，与简单模式一致；预设元数据带 `presetId` 随 GLB 往返，导入的预设赛道可确定性重建。
- 本地文件预设（2026-10-22，两次调整后定型）：**不走用户导入 UI**。本地 `.glb` 放 `public/presets/` 子目录并在 `index.json` 登记文件名 → 运行时 `listLocalPresets` 读取清单、`loadLocalPresetTrack`（GLTFLoader 校验 + meta 覆盖为 preset 模式/稳定 `local-*` presetId/固定 seed）→ 预设下拉出现「本地预设 · <文件名>」，选中“重新生成”激活（新 id、清榜）。清单缺失/为空时仅有内置列表；同时保留代码内 `PRESET_TRACKS` 形式。
