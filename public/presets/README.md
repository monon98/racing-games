# 本地 GLB 预设（public/presets/）

把**本游戏导出的** `.glb` 赛道文件放进本目录，并在 `index.json` 的 `files` 数组登记文件名，即可作为“本地预设”出现在首页预设下拉中：

```json
{
  "files": ["我的环道.glb"]
}
```

规则：

- 文件必须是由本游戏「导出赛道」生成的赛道文件（含中心线数据），否则加载时会被拒绝。
- 预设 ID 由文件名派生（`local-<去扩展名>`），同名文件跨部署保持同一 ID，可安全引用排行榜。
- 环境随固定 seed 布置，同一文件每次加载外观一致。
- 目录可以为空：`index.json` 为空数组或缺失时，首页仅有内置预设，功能不受影响。
- 文件随 Vite 构建打包（`public/` → `dist/`），GitHub Pages 部署自动可用。
