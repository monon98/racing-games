# 物理与规则（physics-and-rules）

入口：`src/physics/vehicle.ts`（车辆）、`src/game/Game.ts`（规则）。

## 车辆（cannon-es RaycastVehicle）
- 底盘：`Box(CAR.width/2, CAR.height*0.26, CAR.length/2-0.05)`，即 `Box(0.85, 0.31, 1.75)` 下偏 0.1m，**整车单一碰撞盒**（2026-10-20 用户要求去掉轮位碰撞盒，以小车为一个完整模型判断碰撞），质量 **750**，线性阻尼 0.05、角阻尼 **0.75**（2026-10-23：旧值 1.0 会让 cannon 按 `pow(1-1,dt)=0` **每步直接清零角速度**，旋转动力学完全失真——表现为转向响应迟钝、翻车被掩盖；0.5 在复杂地形斜坡上侧翻/后溜失控，0.75 保留真实感又压制复杂地形瞬态）。
- 四轮：半径 **0.4**，悬架刚度 45、restLength 0.38、行程 0.25、压缩阻尼 **14**、回弹阻尼 **6**、rollInfluence **0.05**（2026-10-23 从 0.08 下调：真实旋转动力学后切向冲量尖峰更易侧翻）；前轮 z=+1.332、后轮 z=-1.332（`CAR.length × 0.37`），x=±1.0（`CAR.width/2 + 0.15`，轮距外扩），连接点 y=-0.24。frictionSlip **按帧动态设定**：前轴（转向）`GRIP_FRONT=5`，后轴（驱动）`GRIP_REAR=3.2`；前轴随侧偏角在 0.2→0.5 rad 间滚动衰减到 `GRIP_FRONT_SLIDING=3.3`。**重要量级锚点（2026-10-23）**：前轴 10 → 横向加速度实测 ≈2.8g，超整车倾翻阈值（≈1.8g：重心 0.55m/半轮距 1.0m），“油门+满舵”必侧翻；5（≈1.4g）在阈值内且转向响应充足（转向手感的大头收益其实来自防抬头 PD 修复，前轮不再离地）。
- 碰撞回弹（2026-10-20）：撞护栏后沿接触法线（`contact.ni`，统一取从护栏指向车身的方向）**立即回弹**——法向分量重置为向外 `max(0.35 × 冲击, 0.8 m/s)`，切向保留后**整体保留 80% 速度**（`COLLISION_BOUNCE` / `COLLISION_SPEED_RETAIN` / `COLLISION_MIN_IMPACT=1.2`）；接触在 step 中记录、step 后统一施加（`barrierHit`），`reset()` 时清空。低于 1.2m/s 的贴墙低速接触不触发，避免抖动。
- 控制与转向（2026-10-23 重做）：`throttle` 施加于后轮（±7500N，正向取反，0-100km/h 约 1.5s）**+ 四驱叠加**（2026-10-23 用户要求）：前轴每轮额外 `force × FRONT_DRIVE_RATIO`（0.5，前轴总驱动 ≈ 后轴一半），前轮接地时生效、悬空时自然回退为纯后驱（cannon-es 急加速重心后移压空前轮，逐帧对照实验发现直线全油门时前悬架全程伸长极限，直线 0-100/极速几乎不变，起步/出弯/爬坡更有力）；**所有四轮必须每帧都 `applyEngineForce`**——cannon 的 `wheel.engineForce` 跨帧残留，漏设会让倒车转向后的动力残留到前进帧。`brake` 施加四轮（≤55）。转向为**速度敏感曲线 `maxSteerAt(speed)`**：静止 0.65 rad（37°）二次 ease-out 衰减到 `STEER_FALLOFF_SPEED=45 m/s` 处的 0.12 rad（7°）。打角/回正速率**随速度自适应**：按住 `7+8t`、松键 `5.5+8t`（t=speed/45 归一，45m/s 时分别为 15/s、13.5/s）——2026-10-23 实测：固定回正 5.5/s 在 49m/s 松键后转向角滞留 0.25s+，前轮冲量借 yaw 惯量把车甩进大侧偏（“S 转不过来、松手甩尾”的另一根源）。**旧的“转向限速 50km/h（削动力+四轮制动）”已移除**——高速过弯能力随转向角曲线自然衰减，不再有“限速墙”。转向时动力削减保留（`1-0.45×|steer|`）。
- 防抬头：PD 反扭矩（阈值 **0.03**、增益 160000(P)+8000(D)）的抬角度数取**带符号的 `asin(forward·groundNormal)`**（车头相对路面法线）——车身贴合坡面时天然 ≈0（斜坡不误伤），越过 90°（倒栽）方向依旧正确。**2026-10-23 实测教训**：①阈值必须 ≤ 前轮悬垂落空的俯仰角（≈0.023 rad），否则满油门前轮离地、高速转向完全失效；②过强（260000/8000/阈值 0.015）会与后驱扭矩互相纠缠，复杂地形复活点俯仰震荡；③`acos(up·normal)` 版在越过 90° 后把已翻过头的车继续往旋转方向推（复杂赛道坡顶冲出后 py 发散到 -11 rad/s 失控空翻）。上限分档：≥2 轮接地 `PITCH_COUNTER_MAX=20000`，即将离地/空中（<2 轮接触）`PITCH_COUNTER_AIR_MAX=48000`——坡顶瞬间仅 1 轮接触 + 悬架弹射力矩（≈3 万 N·m）会压过地面版上限打出后空翻。
- 漂移模型（2026-10-23 重做，替代旧横摆率翻转启发式）：界定位**车身侧偏角**（`atan2(|横向速度|, |前进速度|)`，前后差速矢量按车体 X/Z 轴）：`>0.35 rad` 且速度 >8 m/s 进入，`<0.15 rad` 或速度 <4 退出（带迟滞，HUD 显示“漂移失控中”）。抓地不再按漂移档切换（前轴已按侧偏角连续滚动）。**重要实证**：cannon-es 冲量轮胎在稳态弯中车身贴轨迹、侧偏角恒 ≈0（只有推头），自发甩尾不存在——真实侧偏只出现在瞬态（撞墙回弹、大转角切换、颠簸、后轮冲量突然变化）。侧滑抑制（松键回正）：无转向输入时衰减横向速度（仅水平分量），强度 `4×max(0.3, 1-slip/0.9)`——小侧偏全量快速回直，深侧偏保底 1.2/s 也能收回（2026-10-23 实测：一刀切门槛 0.25 会让深滑永远收不回来）。
- 滚转稳定（2026-10-23 新增，街机防翻辅助）：接地（≥1 轮）且车身明显侧倾（`up.y < 0.97`）时，沿车头方向施加反侧倾力矩 `min(30000, 160000×roll + 12000×rollRate)`（roll = `asin(车身右轴 .y)`，D 项抵消旋转趋势）；空中不介入。旧角阻尼 1.0 每步清零角速度曾把翻车问题整体掩盖，降低到真实动力学后需要它兜底“油门+满舵”过弯/山坡瞬态。
- 倒车限制：加速力 ×0.65，最高倒车速度 8 m/s；倒车+转向时最高倒车速度改为 **10 m/s（HUD ≈36 km/h）**：四轮全给满力避免原地打转（四驱下同），并对绝对速度做钳制。
- 滑行制动：单纯松油门（无转向）用 COAST_BRAKE=4 缓慢滑行；松油门但按住左右键、或**正在倒车（向后滑行）**时用 ENGINE_BRAKE=50 快速降速（倒车松键快速归零）；按后退键（倒车输入）在前进时按刹车处理，急速降速。
- 空中钳制：**四轮全离地**时上升速度 ≤ 2.0 m/s（仅防极端弹射）；下落完全交给重力（无人工下压力），飞起后自然落回。
- 极速：发动机限速 200km/h（接近上限渐入削减动力）；**下坡允许超速**（不自动刹车）。
- 视觉同步：`getWheelTransform(i)` 返回含转向/自旋的轮子世界变换，直接赋给轮子 mesh。

## 地面物理注意事项
- cannon-es `Plane` 的默认局部法线是 `(0,0,1)`（竖直面），用作水平地面必须 `body.quaternion.setFromEuler(-Math.PI/2, 0, 0)`，否则车辆直接坠落（曾发生“开局即掉落”bug）。
- 旋转后的静态地面必须把四元数放进 Body 构造参数并调用 `body.updateAABB()`：不刷新 AABB 时 broadphase 会按旧包围盒剔除部分轮子射线（曾导致前轮永不触地、转向无效）。
- 复杂模式地面用整片地形顶点构建 `CANNON.Trimesh`（地形优先，道路贴地），另加 y=-30 的水平 Plane 兜底。

## 车辆坐标与手感
- RaycastVehicle 轴配置：right=X(0)、forward=Z(2)、up=Y(1)；该配置下正发动机力沿 -Z 推，因此代码里油门力取反（正油门 = +Z 前进），`customSlidingRotationalSpeed=30` 保持滑动时轮子转向一致。
- 底盘 `linearDamping 0.05 / angularDamping 0.75`；松油门且不踩刹车时按上文滑行制动规则施加制动力。
- 轮子必须作为场景直属子节点并直接应用 `getWheelTransform` 的世界变换（作为车体子节点会双重偏移导致轮子消失）。

## 检测与重生（src/config.ts 有全部阈值）
- 翻车：车身上向量与竖直夹角 > 70° 持续 1s → `respawn('flip')`，`flips+1`（仅记录不展示）。
- 脱轨：水平距离中心线 > 半宽 + 0.5m 持续 0.4s → `respawn('offtrack')`。
- 逆行：仅当“车头朝后（车头与切线点积 < -0.5）且沿车头方向前进 > 2 m/s”持续 3s → 警告并重生；倒车（车头朝前）和车头朝后但向后开都不触发（纯函数 `isWrongWay`，`src/game/wrongWay.ts`）。
- 坠落：y < -8 → `respawn('offtrack')`。
- 重生：放置到最近中心线点上方 `CHASSIS_SPAWN_HEIGHT`（1.05m ≈ 连接点 0.24 + 悬架静止长 0.38 + 轮半径 0.4 + 落差）、朝向切线；`lastS` 重置为重生点弧长。
- 护栏：厚度 **0.8m**、段长 ×1.4 重叠（防弯道缝隙）、离路面边缘 0.05m；物理固定子步必须保持 1/60s（120Hz 会导致松油俯仰失稳翻车）。撞护栏（法向冲击 > 6 m/s）触发镜头震动 + 红闪反馈（`onBarrierCollide`）。
- 护栏高度 **1.1 × 车高（1.32m，车缩小后）**；护栏段按“两端采样点的实际路面边缘”对齐（随弯道加宽）。

## 惩罚公式
- 时间惩罚：每次重生 `+3000ms`。
- 距离惩罚：`max(0, lastS - 重生点弧长)` 累加（进度回退距离，米）。
- 单圈用时 = 墙钟耗时 + 时间惩罚 + 距离惩罚 × 0.1s/m，均计入排行榜。

## 冲线
- 进度：弧长 s 增量处理回绕（超过半圈视为跨越起点）；用纯函数 `updateLapProgress`（`src/game/lapProgress.ts`）先判断冲线、再更新 `lastS`（顺序颠倒会导致永不冲线）；`completedDistance > 0.7 × totalLength` 且 s 从尾部跨到头部才冲线。
- 冲线后写入 `LeaderboardEntry`（含 flips，不展示）并显示结算浮层。
